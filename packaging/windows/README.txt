CAPTION REMOVER for Windows · The Tru Studio
=============================================

INSTALL
1. Right-click the zip file > "Extract All".
2. Open the extracted folder and double-click "Caption Remover.exe".
   - If Windows shows "Windows protected your PC": click "More info", then "Run anyway".
     (The app isn't code-signed yet; this message goes away once it is.)
3. Click OK to install. It's added to your Start menu and desktop.
4. The first launch downloads its AI components (about 1.5 GB, or about 3 GB with an
   NVIDIA graphics card). A progress window shows each step. Keep the PC online.
5. After that, Caption Remover opens straight away. You can delete the zip and the
   extracted folder.

NEEDS
- Windows 10 or 11, 64-bit, 8 GB RAM or more (16 GB recommended).
- An NVIDIA graphics card is used automatically if present. Without one it runs on
  the processor, which is slower.

UPDATES
The app checks for updates when it opens (Settings > Updates). Updates install
from inside the app in seconds.

UNINSTALL
Settings > Apps > Installed apps > Caption Remover > Uninstall.
Your cleaned videos (Videos\Caption Remover) are kept.

TROUBLESHOOTING
Log file: %LOCALAPPDATA%\Caption Remover\log.txt
